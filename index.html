Opción A: Google Apps Script Web App

100% Gratuito y sin límites. No requiere cuenta de Google Cloud ni tarjetas de crédito.

Recomendada
¿Cómo obtener la URL en 3 pasos (1 minuto)?
  1. Ve a script.google.com y pulsa en "Nuevo proyecto".
  2. Borra el código que aparezca y pega el script de ClipFlow.
  3. Pulsa arriba a la derecha en Implementar > Nueva implementación:
    • Tipo: Aplicación web
    • Ejecutar como: Yo
    • Quién tiene acceso: Cualquier usuario
  4. Pulsa en Implementar, autoriza los permisos y copia la "URL de la aplicación web" generada.
Opción B: Google Drive API Key

Para desarrolladores con proyecto en Google Cloud Console y API v3 habilitada.
